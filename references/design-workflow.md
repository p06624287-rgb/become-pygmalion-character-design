# 二维设计工作流

## 参考先于精修

将参考分成：用户自己的已确认设计、外部设计灵感、画风参考、材料/结构/文化依据。一张图可以有多个明确作用，不自动把外部角色的身份和服装变成新角色正本。问清“喜欢什么”与“保持什么”，冲突时明确各图控制范围。

没有参考时，依据已知定位、职业、气质、时代、材料或造型问题在Pinterest检索。实际看图后筛选少量有差异的参考，提供可查看图片/链接、各自用途与推荐理由，让用户表达偏好。不要只交搜索词，也不要凭搜索标题假装看过图片。有图但存在局部缺口时只补缺口。用户拒绝搜索或指定其他渠道时尊重其选择。

Pinterest是发现入口，不是文化事实或版权授权的证据。能追溯则记原作者和原始链接，不能则标未知；不未经授权创建公开画板或转载。页面/登录不可用时如实说明，使用可访问的结果或请用户补图，不绕过访问限制。

对少量核心元素记录：**来源 → 可观察特征 → 与角色的关系 → 如何变形与落位 → 使用边界**。例如借某种工艺的接缝组织来表达职业，而不是照抄参考人物整套标志物。生产模式可一句话配图；产学模式展开参考与结果对照。不要求每个扣子都写论文。

文化、神话、工艺等研究按需要启用，涉及真实历史或习俗时核查可靠来源。形状与性格的对应是设计选择而非自然定律，不用未定义的数值评分制造客观性。

## 阶段交付与评审

以下是有依赖的设计主线，不是必须逐格回复的问卷。数量按差异、用途和预算决定；已有合格资产可以直接复用。身高、头身比、人体或非人体结构均由角色需求决定。

| 阶段 | 实施与图像交付 | 通过条件 |
| --- | --- | --- |
| S00 启动与盘点 | 记录模式、3D选择、素材、用途与授权；不为盘点强行生成图片。 | 知道已有和缺少什么、哪些不能改。 |
| S01 角色任务书 | 简洁Character Brief：定位、气质、生活方式/行动、必要叙事信息、视觉重点与限制。完整故事可选，未知项可暂留。 | 信息足够支持视觉判断，无重大冲突；不用编写长故事填满表格。 |
| S02 参考与画风 | 看参考、按需搜索；画风未明时以同内容小样对照。记录线条、形体夸张、阴影、材质和细节密度；有已确认风格就复用。 | 在大规模部位设计前确定主画风，不只以画师/游戏名替代可观察的约束。 |
| S03 整体方向 | 同一画风下出低完成度全身方向图，比轮廓、大小形、姿态和气质；选择母方向。 | 辨识点与定位相符，选择获确认或在代选授权内。 |
| S04 头脸与身体 | 出头脸/发型比较或修正图、全身比例基准；按需补侧面。先分开主要变量，再整合。 | 身份清晰、比例和重心符合设定、头颈肩协调。测头身比不要把蓬松发顶当颅顶。 |
| S05 服装与道具 | 出中完成度服装方案、关键道具及必要的结构/使用状态图。先穿着层次和大形，再材料与装饰。融合方案明确主方案和借用项。 | 闭合、活动、开合、保护、收纳与佩戴可解释；次要件不强制独立大量探索。 |
| S06 整合与配色 | 出全身整合图、同姿态配色对照或定向修订；必要时补挂点、接触局部图。 | 身份、比例、服装与风格一致，视觉焦点和留白合理，无明显悬空连接；比较配色时不同时换结构。 |
| S07 表演适配 | 按用途出表情、姿态与道具使用图；单张立绘可只检查目标姿势。 | 仍是同一角色，动作和物品状态成立；不声称静态动作证明实际动画可用。 |
| S08 可选差分与连续性 | 需要才出服装/时间/剧情版本；需要叙事才出同场景关键帧。记录共用、改变与移除项。 | 角色身份和基准稳定，手、配饰、道具位置与状态连续。多角色按需检查彼此辨识度。 |
| S09 最终交付 | 高完成度主立绘；按需三视图、表情、局部、色材说明和资产索引。干净原图与展示排版分开。 | 交付范围齐全，实际视觉验收，缺陷与未验证项明确；需要作品集才整理关键过程页。 |
| S10 可选3D | 只交接主skill末节列出的Charakuru官方入口和已确认二维成果。 | 未选3D则不启用；三维输入、步骤与验收完全由官方skill决定。 |

S02确定“怎样画”，S06确定“角色具体用什么配色与材料”，不互相重复。已经确认的全身设计可以从缺口、表演检查、交付或官方3D交接开始，不为满足表格重画所有阶段。

## 每轮评审的具体执行

1. 出图前明确本轮问题、主参考、保持项、改变项和完成度；选图或混合方案时避免隐式拼接全部细节。
2. 直接生成/编辑图像；候选尽量同姿态、机位、景别和光照。结构图用清晰背景与可读边界，展示图才按用途增加景深和戏剧光影。
3. 查看实际图像，按本轮相关维度评审：身份、体型/比例、层次与功能、视觉焦点、风格和交付完整性。具体指出部位和关系。
4. 硬性缺陷先处理，审美多解则解释取舍。保留已确认项，局部修订后复查全图。建议是建议，不把推荐方案写成用户已选方案。
5. 记录问题、变更、保持项、选择依据和状态；按模式决定教学深度，然后进入下一轮或阶段。

“缺少深度”不必等于添加纹样：可以改轮廓、材料对比、功能细节或叙事锚点，也可以删去无关装饰。不要强制繁简交替的固定节奏或对所有人物追加饰品、露肤和伤痕。

道具结构持续失败时先区分参考冲突、输入歧义与生成能力限制，采用局部说明或降低无用复杂度，必要时标注未验证。没有选择3D的用户不应被自动转入建模任务；已选择者仅交接Charakuru，不临时发明另一条机械建模路线。

## 交付与变更

保留可复用原图和少量关键决定，不要求归档每次聊天或每张废稿。主参考应明确控制身份、画风与结构的范围；专门结构修订可优先于总图的简化，但冲突仍需解决并同步，不悄悄推翻用户决定。

用户改头脸、发型、身体或主画风时列出受影响资产，再局部同步。不同服装版本共享已确认身份，移除衣物时检查附着其上的配件。只记录工具实际提供的提示词、输入图、设置和输出，不编造生成参数。

作品集按真实的任务—比较—选择—结果组织，主立绘突出，参考、三视图、色卡和解释从属；不为伪造过程而补做草稿。静态、连续状态、视频和技术验证分开陈述，不因为文件名含FINAL或QA就认为已通过。
